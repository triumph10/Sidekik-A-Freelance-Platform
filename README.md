# Sidekik-A-Freelance-Platform
Sem VI Project  
A smart freelancing platform that connects clients with skilled freelancers using AI-driven recommendations and real-time market insights.

## 🔍 Overview  
Side-Kik enhances the freelancer hiring process by:
- Recommending freelancers using **NLP (BERT)** and **ANN (FAISS)**.
- Allowing freelancers to sell **pre-built projects**.
- Showing **real-time market trends** via the **Adzuna API**.
- Delivering a **personalized search experience** using **Elasticsearch** and FAISS.

## 🛠️ Tech Stack  
- **Frontend**: HTML5, CSS3, JavaScript (ES2024)  
- **Backend**: Python 3.12, Flask  
- **Database**: Supabase  
- **ML/NLP**: BERT, FAISS  
- **Tools & APIs**: Hugging Face, Adzuna API, Jupyter, Git/GitHub

## 🧠 Features  
- AI-powered freelancer matching  
- Marketplace for freelancers' pre-built projects  
- Trend insights for clients and freelancers  
- Personalized project search
